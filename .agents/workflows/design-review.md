# /design-review
1. Load `design-system-ux`. Compare against the project's Design Brief tokens and components.
2. Check: hierarchy, spacing/type consistency, states (hover/focus/loading/empty/error), responsive behavior, contrast, keyboard path, touch targets, microcopy clarity.
3. Run the anti-generic checklist; flag template habits.
4. Output findings by severity with a concrete fix each, and list quick wins first.
