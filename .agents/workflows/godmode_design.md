# GODMODE Autonomous Design Workflow (`/godmode-design`)

> **Goal:** Create professional, anti-slop UI/UX design systems and implement stunning, responsive web interfaces.

---

## Stage 1: Brand & Style Definition
- Select target UI style (Soft UI, Minimalist, Enterprise, Brutalist, Luxury).
- Choose typography pairing (Header + Body Google Fonts).
- Generate WCAG AA compliant color palette (Primary, Secondary, Accent, Surface).

## Stage 2: Layout & Component Architecture
- Define responsive grid layout (Mobile 375px → Desktop 1440px).
- Select Lucide/Heroicons SVG iconography (no emojis as icons).
- Tune CSS transitions (150–300ms cubic-bezier) and hover states (`cursor-pointer`).

## Stage 3: High-Aesthetic Implementation
- Implement CSS variables and component tokens in `index.css`.
- Build responsive UI components handling all 5 UI states (Loading, Empty, Error, Success, Offline).

## Stage 4: Quality & Accessibility Audit
- Audit color contrast (4.5:1 minimum ratio).
- Test keyboard navigation focus rings and `prefers-reduced-motion`.
- Deliver anti-slop, production-ready interface.
