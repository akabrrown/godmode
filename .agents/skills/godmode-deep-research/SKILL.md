# GODMODE Deep Research & Intelligence Engine

## Overview
Powered by ByteDance's `deer-flow` Deep Research architecture. Orchestrates recursive web research, academic paper analysis, GitHub codebase exploration, and synthesis into comprehensive intelligence reports.

## Research Process Lifecycle

```
┌─────────────────┐     ┌──────────────────┐     ┌───────────────────┐     ┌─────────────────┐
│ 1. RESEARCH PLAN│ ──> │ 2. EXPLORATION   │ ──> │ 3. SYNTHESIS      │ ──> │ 4. CITATION AUDIT│
│ Scope queries,  │     │ Recursive search,│     │ Extract insights, │     │ Cross-verify    │
│ domain selection│     │ web crawling     │     │ identify trends   │     │ source URLs     │
└─────────────────┘     └──────────────────┘     └───────────────────┘     └─────────────────┘
```

## Step-by-Step Execution

1. **Research Scoping:** Formulate core research questions, key sub-topics, allowlisted domains, and source search queries.
2. **Recursive Search & Crawling:** Execute targeted search queries. Parse documentation, paper abstracts, GitHub repos, and technical articles.
3. **Evidence Extraction & Deduplication:** Filter out low-quality/redundant sources. Extract empirical evidence, benchmark data, and architectural patterns.
4. **Structured Intelligence Synthesis:** Organize research into clear sections: Executive Summary, Key Findings, Technical Comparison Matrix, Trade-offs, and Recommendations.
5. **Citation Verification:** Ensure all facts, statistics, and claims link directly to verified source URLs or code snippets.
