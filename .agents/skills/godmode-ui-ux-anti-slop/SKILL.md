# GODMODE UI/UX Anti-Slop Design System

## Overview
Eliminates AI UI "slop" (generic purple/pink gradients, default glassmorphism clichés, poor typography, cramped spacing) by combining the anti-slop directives of `taste-skill`, the 161 reasoning rules and 84 UI styles of `ui-ux-pro-max`, and Antigravity's high-aesthetic guidelines.

## 1. Anti-Slop Design Principles

```
  BANNED (AI SLOP)                      GODMODE PREMIUM STANDARD
  ────────────────                    ─────────────────────────
  ✖ Generic purple/pink gradients      ✔ Curated HSL color palettes tailored to brand mood
  ✖ Default browser fonts              ✔ Modern Google Fonts typography pairings (e.g. Inter + Outfit)
  ✖ Untuned glassmorphism everywhere   ✔ Purposeful elevation, depth, shadows, and subtle borders
  ✖ Instant state changes              ✔ Smooth, tuned CSS transitions & spring physics (150-300ms)
  ✖ Emojis as icons                    ✔ Clean, vector SVG icons (Lucide, Heroicons, FontAwesome)
  ✖ Static pixel offsets (+12px)       ✔ Responsive, fluid layout math using rem/em and flex/grid
```

## 2. Design System Generation Workflow

1. **Target Brand & Mood Definition:** Identify project category, audience, and visual style (e.g., Soft UI, Minimalist, Brutalist, Enterprise, Neo-Brutalism, Luxury).
2. **Typography Pairing Selection:** Select harmonized header and body font combinations (e.g., Cormorant Garamond + Montserrat for Luxury, Outfit + Inter for Modern SaaS).
3. **Harmonious Color Palette Generation:** Define Primary, Secondary, CTA Accent, Background, and Contrast Surface colors with WCAG AA compliance (4.5:1 text contrast minimum).
4. **Motion & Interaction Tuning:** Set transition timings (150–300ms cubic-bezier), hover states with `cursor-pointer`, focus rings for keyboard navigation, and `prefers-reduced-motion` fallbacks.
5. **Pre-Delivery UI Checklist:**
   - [ ] No emojis used as functional icons.
   - [ ] `cursor: pointer` applied to all clickable elements.
   - [ ] Smooth hover & focus transitions on interactive items.
   - [ ] Light/Dark mode contrast ratio passes WCAG AA.
   - [ ] Tested across 375px, 768px, 1024px, and 1440px viewport breakpoints.
