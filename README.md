> It synthesizes the foundational paradigms of 10 world-class agent frameworks into a unified, zero-compromise runtime.

## Synthesized Framework Heritage

GODMODE is distilled from the strengths of:

1. **`agent-skills`** — Granular, on-demand skill isolation and capability routing.
2. **`caveman`** — Hyper-dense token discipline, minimal conversational filler, byte-exact diffs.
3. **`deer-flow`** — Autonomous sub-agent harness, sandboxed execution, and persistent memory indexing.
4. **`marketingskills`** — Conversion psychology, CRO, copywriting, and technical launch mechanics.
5. **`superpowers`** — Strict Red/Green/Refactor TDD gates and anti-rationalization discipline.
6. **`taste-skill`** — Anti-slop visual taste, modern typography, glassmorphism, dynamic motion.
7. **`ui-ux-pro-max-skill`** — 5-state UI handling (loading, empty, error, success, offline) and accessibility.
8. **`LibreChat`** — Transparent tool intent streaming, provider/model telemetry, and cost attribution.
9. **`OpenMontage`** — Rule Zero pipeline manifests, multi-stage director execution, and checkpoint validation.
10. **`antigravity-config-v2`** — Unified workspace integration and system-level rules enforcement.

### Pillar I: Rule Zero (Pipeline-Driven Architecture)
*Derived from OpenMontage*
Every non-trivial deliverable (software build, deep research, UI/UX overhaul, marketing campaign, media synthesis) runs through a structured pipeline manifest with explicit preflight checks, director skills, provider guidance, and review checkpoints.

### Pillar II: Anti-Rationalization & Red/Green TDD
*Derived from superpowers & agent-skills*
Shortcuts are banned. All code changes adhere to strict **Red/Green/Refactor TDD**: write failing test first, verify failure, write minimal implementation, pass test, refactor cleanly with zero regressions.

### Pillar III: Caveman Token Discipline
*Derived from caveman*
Information density is maximized. Conversational fluff, generic apologies, and narrations are eliminated while code, diffs, shell commands, and terminal errors remain 100% byte-exact.

### Pillar IV: Transparent Tool Intent & Outcome Telemetry
*Derived from LibreChat*
Every tool call streams its target intent as its first parameter. Operations announce provider, model, tool name, and estimated resource cost prior to execution, resolving to outcome patches upon completion.

### Pillar V: Harness Sub-Agents, Memory & Sandboxing
*Derived from deer-flow*
Isolated sub-agents run in parallel with clear context boundaries. Persistent memory tracks architectural decisions and contracts across turns, backed by sandboxed workspace safety.

## Dual Quality Gates

Before any deliverable is marked complete:

### 1. Skeptic Gate
- Would a senior engineer, designer, product marketer, or code auditor suspect AI involvement?
- Zero AI tells survive: no generic purple/pink gradients, no template hero sections, no fluff comments, no uniform commit messages, no lazy error handling.

### 2. Production Gate
- If an adversary had full source access, a browser console, and unlimited time, what is the worst they could do?
- Never rely on an attacker "not thinking to try it".
- Server-side authentication and authorization verified on every record ID (IDOR prevention).
- All 5 UI states handled: **Loading**, **Empty**, **Error**, **Success**, and **Offline**.
- Client and server validation on all inputs. Zero leaked secrets.

## Installation & Setup

### For Google Antigravity
Clone or place this repository into your workspace root or global config root:
```bash
git clone https://github.com/akabrrown/godmode.git
```
Antigravity automatically discovers and binds `.agents/` as its workspace customization root.

### For Claude Code / Cursor / Codex
Copy or symlink `.agents/AGENTS.md` to `AGENTS.md` at your project root. The rules and skills will be discovered and applied dynamically.

### For LibreChat Web Portal
1. Run `npm install && npm run build` in this directory.
2. In LibreChat's `librechat.yaml`, the `godmode` MCP server is pre-configured:
```yaml
mcpServers:
  godmode:
    type: stdio
    command: node
    args:
      - "c:\\Users\\Dell\\Desktop\\PROjects\\Agent GODMODE\\dist\\bin\\godmode.js"
      - mcp
    timeout: 300000
```
3. Start LibreChat: all 289 skills are instantly available as native agent tools.
